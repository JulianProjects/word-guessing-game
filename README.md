# Java Word Game

> Status: Work in Progress

A small Java word game focused on basic game logic, user input, and object-oriented programming.

This project is developed as a learning and portfolio project. It demonstrates a simple console-based game structure using Java, including input handling, game flow, and basic validation.

## Features

- Console-based word guessing gameplay
- Basic user input handling
- Simple game loop
- Object-oriented project structure
- Easy to compile and run from the command line
- Clean repository structure for GitHub documentation
